Colas FIFO en Python

Administrar la cola

Agregá elementos manualmente o dictalos por voz.

Para usar la voz, permití el acceso al micrófono. La función depende del navegador y suele requerir HTTPS o localhost.

Regla FIFO: el primero en entrar es el primero en salir.

Funciones del código

  • encolar(queue, element): agrega al final.
  • desencolar(queue): retira el primero.
  • esta_vacia(queue): comprueba si está vacía.
  • obtener_cola(): muestra la cola actual.
